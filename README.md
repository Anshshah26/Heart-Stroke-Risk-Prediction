🚀 Overview

HeartGuard AI is a Machine Learning-powered healthcare application that predicts the likelihood of heart disease based on patient health parameters.

The project combines Data Science, Machine Learning, and an interactive Streamlit web application to help users understand their potential cardiovascular risk through a simple and intuitive interface.

This solution demonstrates how AI can assist in early health risk assessment and support preventive healthcare decisions.

📊 Input Parameters

The model predicts heart disease risk using important medical attributes such as:

Feature	Description
Age	Patient Age
Sex	Gender
Chest Pain Type	Type of Chest Pain
Resting Blood Pressure	Blood Pressure Level
Cholesterol	Serum Cholesterol
Fasting Blood Sugar	Blood Sugar Level
Resting ECG	Electrocardiographic Results
Maximum Heart Rate	Achieved Heart Rate
Exercise Induced Angina	Chest Pain During Exercise
ST Depression	ECG Measurement
Slope	Slope of Peak Exercise ST Segment
Number of Vessels	Major Blood Vessels
Thalassemia	Blood Disorder Indicator
